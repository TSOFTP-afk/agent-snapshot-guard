# Agent Snapshot Guard

**AI 编程工具在你电脑上存了什么、背地里传了什么——看见它，然后自己决定管不管。**

一个社区开源的小工具。不站队、不点名、不替你做决定。

---

## 屋子里有蟑螂的时候

某 AI 编程工具被曝在后台把用户整个工作区打包上传——连 `.git` 历史都不放过，应用内没有开关，隐私设置也拦不住。官方道歉、修复、承诺开源，然后呢？

这不是孤例。国外爆过，国内也爆。老话说得好：**当你发现屋子里有一只蟑螂的时候，蟑螂已经爬满全屋了。**

- 除了少数代码公开的开源 agent，**闭源工具在你电脑背后干了什么，没人知道**
- 个人开发者确实大多不在乎数据安全；可一旦涉及**商业代码、客户数据、内部文档**，to B 场景的隐私是实打实的红线
- 市面上缺一个东西：把 AI 工具在你本机的数据行为变得**可见、可控、可取证**

这个项目就是来填这个坑的。它是社区级的、最小的、诚实的——不吹“企业级安全”。

## 它做什么

三步，每步都是你亲自按的：

```powershell
# Windows 10/11 · PowerShell 5.1+ · 无需管理员
git clone https://github.com/TSOFTP-afk/agent-snapshot-guard.git
cd agent-snapshot-guard

.\AgentSnapshotGuard.ps1 examples            # ① 看看有哪些现成模板（惰性，什么都不发生）
.\AgentSnapshotGuard.ps1 enable -App <name>  # ② 启用观察：只记录，不删除
.\AgentSnapshotGuard.ps1 status              # ③ 看它观察到了什么
.\AgentSnapshotGuard.ps1 arm -App <name>     # ④ 看清楚后，你决定武装（拒写+删除+隔离）
```

`status` 长这样：

```
[*] engine: active-rules=1  sentinel=running (pid 13164)  autostart=yes
[*] APP            MODE      EVIDENCE    ARTIFACTS-NOW
  <your-app>     observe   community   3
```

反悔随时可以：

```powershell
.\AgentSnapshotGuard.ps1 disarm -App <name>   # 撤回观察
.\AgentSnapshotGuard.ps1 disable -App <name>  # 彻底关闭
.\AgentSnapshotGuard.ps1 uninstall            # 全部撤干净，像没装过一样
```

## 出厂原则：零规则、零武装、零立场

- 引擎本身**不包含任何针对具体产品的规则**；随仓库附带的模板全部在 `examples/`，是惰性的——`enable` 之前一个字节都不碰你的盘
- 观察模式**只记录不删除**；删除/拒写必须你显式 `arm`
- 只在工具自己的数据目录里活动；你的项目、你的 `.git`、你的工作区，引擎碰都碰不到
- 每一次删除/隔离都带 SHA256 留痕，可查证、可恢复
- 自带工具？复制 [`custom.example.json`](examples/custom.example.json) 改改就能接（[规范](docs/RULES.md)）

## 🪤 能拦住什么，拦不住什么

说实话：

**能拦：**
- 已知路径的快照/检查点产物在**落盘环节**（拒写让它直接失败）
- 已知模式的产物文件（上传前的本地环节，发现即毁）
- 已知遥测域名（可选网络层，需管理员）

**拦不住：**
- 厂商换存储路径、换协议、改文件特征——猫鼠游戏，规则库需要社区持续更新
- 纯服务端行为（你看不见的东西拦不了）
- **真正强力的隐私保护**（沙箱隔离、全流量审计、DLP）——那是商业公司的活，社区工具做到“可见性 + 最低限度拦截”就是本分

说白了：这个工具是纱窗，不是保险库。但有纱窗总比敞着门强。

## 四层防御

| 层 | 手段 | 一句话 |
|---|---|---|
| L0 | 观察模式 | 只记录不删除，默认姿态 |
| L1 | ACL 拒写 | 危险目录创建即失败，属主权利无需管理员 |
| L2 | 歼灭哨兵 | 每 5 秒扫描，SHA256 留痕 |
| L3 | 网络隔离 | 可选、需管理员 |

## ❓ FAQ

**我该启用哪些模板？**
自己看、自己定。这个工具的立场就是不替你做这个决定。

**会动我的项目文件吗？**
不会。规则只能指向工具自己的数据目录，你的项目、`.git`、工作区是硬红线（[规范](docs/RULES.md)）。

**会拖慢电脑吗？**
每 5 秒枚举几个数据目录，无服务、无驱动、无驻留注入。

**支持 Mac/Linux？**
目前 Windows（PS 5.1+）。规则是 JSON，欢迎 PR。

**模板数据可信吗？**
全部来自社区公开观察，惰性、附来源；标 `verified` 的必须附可复现取证。不信任就自己核实，或干脆自己写一份。
